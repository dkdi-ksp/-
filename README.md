# 我的课程表

一个装在手机上的课程表。手动录入课程，支持单双周与起止周，上课前提醒你。

纯静态网页，**不用注册、不上传任何数据**——课程只存在你自己手机的浏览器里。可以「添加到主屏幕」当成 App 用，没网也能打开。

## 在电脑上试

双击 `启动.bat`：它会开一个小服务器并打开 `http://localhost:8080`。
想跑自动化测试，双击 `测试.bat`。

## 装到手机上

用手机浏览器打开本站网址，然后：

- **安卓 / Chrome**：右上角菜单 →「添加到主屏幕」
- **iPhone**：必须用 Safari → 分享按钮 →「添加到主屏幕」

> `.ics` 日历导出和「App 内通知」都要求 `https://`，局域网 IP 打开时用不了。

## 提醒怎么才准时

浏览器的定时器在锁屏或切走之后会被冻结，所以**App 内通知只能算补充**。
可靠的提醒是：设置页 →「导出到手机日历」→ 把 `.ics` 导入系统日历。之后由手机系统负责，App 关着也会响。

## 备份

课程存在浏览器本地，**清除浏览器数据就会全丢**。请用设置页的「导出备份」定期存一份。

## 开发

零 npm 依赖，没有构建步骤。直接改 `js/`、`css/` 里的文件即可，刷新浏览器就生效（离线缓存可能要先改 `sw.js` 里的版本号）。

```
node --test        # 跑全部测试（85 个）
node server.js     # 本地服务器，默认 8080 端口
```

模块清单与设计文档见 `docs/superpowers/`。详细的使用说明见 `使用说明.md`。
